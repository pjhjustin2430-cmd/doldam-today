# 시연 영상 대본 (1분 30초)

녹화: `Win + Alt + R`(Xbox Game Bar) 또는 OBS. 브라우저 창 1280x720 이상, 북마크 줄·알림 끄기.
시작 주소: https://doldam-today-2m16.vercel.app  (돌담지기 질문은 미리 한 번 해 보고 답이 나오는지 확인)

| 시간 | 화면 | 말할 내용 |
|---|---|---|
| 0:00~0:10 | 홈 (지도, 오늘 날씨 칩) | "제주 돌담을 오늘 날씨에 맞춰 골라 주는 돌담 오늘입니다. 14곳이 종류별 색으로 표시돼요." |
| 0:10~0:25 | 지도에서 '감수굴' 클릭 → 상세 | "명소를 누르면 실제 지도 위에 공공데이터 실측 경로가 고도 색으로 보입니다." 위성 버튼 눌러 보여 주기 |
| 0:25~0:40 | 돌담 도장 클릭 → 내 수첩 | "도장을 찍으면 Supabase에 저장돼 새로고침해도 남고, 수첩에 사진과 함께 쌓입니다." 새로고침 한 번 |
| 0:40~1:05 | 바람과 돌담 | "기상청 오늘 풍속을 3D 돌담에 불어 넣었어요. 담 뒤에서 바람이 약해집니다." 마우스로 돌리기 → 슬라이더 올리기 → 돌담 치우기 |
| 1:05~1:25 | 돌담지기 팝업 | 질문 입력: "오늘 바람 센데 갈 만한 돌담 어디야?" → "AI가 날씨와 명소 도구를 스스로 골라 호출했고, 호출 내역이 답 위에 보입니다." |
| 1:25~1:30 | 홈 또는 QR 슬라이드 | "감사합니다." |

## 체크
- 돌담지기가 답하려면 Anthropic 키/크레딧이 유효해야 함 (Vercel 환경변수 ANTHROPIC_API_KEY, 시연은 ANTHROPIC_MODEL=claude-haiku-5-5)
- 3D 화면은 처음 불러올 때 몇 초 걸리니 미리 한 번 열어 둘 것
